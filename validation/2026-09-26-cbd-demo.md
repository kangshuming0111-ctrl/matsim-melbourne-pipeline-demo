## Controlled experiment

The [recorded selection rule](2026-09-26-capacity-selection.json) chose the
highest-volume eligible car link using only the baseline's entered-link events,
before observing the proposal result. The selected link was 255, with 171
entered-link events. This is a traversal count, not unique users or hourly flow.

The actual network XML comparison confirms exactly one directed link changed:
its configured capacity went from 1,200 to 600 per hour. Reverse-direction
inclusion was requested, but no exact reverse car link was available. Node/link
IDs, geometry, speeds, lanes and modes were unchanged. Input plans have the same
SHA-256; generated configurations are identical apart from network/output paths;
the MATSim seed is 4711 and both runs completed three iterations.

Car mean trip time changed from 219.068522 to 219.089936 seconds: **+0.021413
seconds**. All-mode trip-weighted mean time changed by **+0.005520 seconds**.
Trip counts, modal counts and mean trip distances did not change. This is a
near-null response in this particular model run, retained without selecting a
different intervention to obtain a more favourable result.

## Reproducibility and remaining limits

- [Reproduction guide](../docs/REPRODUCIBLE_DEMO.md) covers prerequisites, data,
  fresh jobs, the intervention, independent report generation and interpretation.
- The runs used an existing local Python environment, data and cached Docker
  images. A clean-machine or cold-image build was **not** verified today.
- The recorded Git baseline was `55a3dd8` with a dirty working tree. Runtime
  source hashes were collected during report verification; this is not a full
  archived checkout or proof of independent authorship of every file.
- The demand-location/network bounding-box diagnostic was 69.1%; it is not
  polygon coverage, data accuracy or model validation. Its implications require
  further investigation before broader transport interpretation.
- A single seed and three iterations do not demonstrate convergence,
  significance, calibrated prediction or long-term city development. Public
  transport is teleported, not timetable-based. Effective QSim capacity may
  differ from network input capacity.
- Raw plans, events and source datasets were not published or packaged. No
  changes were pushed to GitHub as part of this task.
